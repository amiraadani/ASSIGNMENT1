# [Project Title]
Receiptra: OCR And Predictive Analysis Expense Tracker

A web-based expense tracker that helps individuals record expenses using OCR, analyse spending patterns and predict future expenses using machine learning.

## Problem statement
Individuals, particularly students and young adults, often face difficulties managing their daily expenses and monthly budgets. Manual expense recording can be time-consuming and may result in inaccurate or incomplete financial records. Furthermore, limited spending analysis and predictive capabilities make it difficult for users to understand their spending patterns and estimate future expenses. Therefore, a web-based expense tracking system integrating Optical Character Recognition (OCR) and machine learning is proposed to simplify expense recording, analyse spending patterns and predict future expenses.
