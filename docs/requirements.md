# Requirements

## Functional requirements (what the system must DO)
1. The system shall allow users to upload receipt images and extract available transaction details, including merchant name, transaction date and total amount using Optical Character Recognition (OCR). (FR1)

2. The system shall allow users to review and correct extracted receipt information before saving it as an expense record. (FR2)

3. The system shall allow users to add, view, edit and delete expense records, including the date, amount, category and payment method. (FR3)

4. The system shall display expense summaries and spendeing analytics, including monthly expenses and spending by category. (FR4)

5. The system shall predict the following month's expenses using historical expense data and display the prediction on the dashboard. (FR5)

## Non-functional requirements (how the system must PERFORM)
1. The system shall display dashboard summaries within 3 seconds under normal operating conditions. (NFR1)

2. The system shall protect users' financial records through authentication, access controls and secure password storage. (NFR2)

3. The system shall validate required expense information and allow users to correct inaccurate OCR results before saving records. (NFR3)
